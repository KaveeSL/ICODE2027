# ICODE2027

International Conference on Open and Digital Education — University of Moratuwa / CODL.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- React Router
- Framer Motion
- Lucide icons

## Design direction

UI inspired by [ceynk.lk](https://ceynk.lk/): Inter + Instrument Serif, lime accent CTAs, soft `#F5F5F7` cards, pill buttons, glass surfaces, and section eyebrow labels.

Information architecture follows the ICODE2026 site structure (home sections, call for papers, registration, programme, governance, gallery, proceedings) with refreshed 2027 content.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
